# Code of Conduct

YALTI Prompter is a small, friendly open-source project. We want everyone who uses, discusses or
contributes to it to feel welcome and safe.

## Our standards

We expect participants to:

- be kind, patient and respectful, including when disagreeing;
- assume good intentions and give constructive, specific feedback;
- welcome newcomers and people of every background, identity and level of experience;
- respect people's privacy — never share someone else's personal information or private material.

The following are not acceptable: harassment, insults or personal attacks; discriminatory or
sexualized language or imagery; trolling; threats; and publishing others' private information.

## Scope

This code applies in all project spaces — issues, pull requests, discussions and any other channel
where someone represents the project.

## Enforcement

Maintainers may edit or remove contributions and may temporarily or permanently ban anyone whose
behavior is inappropriate. To report a problem, contact the maintainers privately through the
contact options on the project's GitHub page (or a private security advisory if nothing else is
available). Reports are handled confidentially.

This code is inspired by the [Contributor Covenant](https://www.contributor-covenant.org/).
